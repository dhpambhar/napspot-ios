# NapSpot architecture

Native SwiftUI, iOS 17+, iPhone and iPad, no backend, no third-party packages.
Project generated by XcodeGen from `project.yml` (same setup as RingSpin and MeadowMahjong).

## Layers

```
Game/      pure Swift, no UI, fully unit-tested
  SeededRandom   SplitMix64: same seed -> same board on every device and OS version
  CellSet        100-bit set of cells (two UInt64), the solver's workhorse
  Geometry       rows, columns, regions and "blockers" (cells a cat rules out) per cell
  Puzzle         size, region per cell, solution column per row, givens, difficulty
  LogicSolver    human techniques, in order: single, confinement, touch, pigeonhole.
                 Also the hint engine: nextDeduction(state) explains one step.
  BruteSolver    counts solutions (stops at a limit); used by the generator and tests
  Generator      solution -> grow regions -> hill-climb cell moves until the board has
                 one solution AND LogicSolver can finish it without guessing.
                 Fallback after 30 restarts: add solution cats as givens until it can.
  LevelPlan      level -> size (5x5 ... 10x10), seed, givens; day -> daily seed and size
  GameModel      marks, hearts, timer, undo, auto-X, hints, win/lose (@Observable)
Support/   ProgressStore (UserDefaults), Haptics
UI/        Home, Game (board + toolbar), Win/Lose cards, How to play, Stats, Settings
```

## Why generate instead of shipping levels

Boards come from a seed, so nothing is stored or downloaded and the daily puzzle is
identical for every player. The prototype (Node, kept out of the app) showed:

| size | restarts / board | time / board (JS) |
| --- | --- | --- |
| 5–7 | < 1 | < 5 ms |
| 8 | 1.5 | 20 ms |
| 9 | 1.4 | 100 ms |
| 10 | 9 | 1.5 s, ~10% need the givens fallback |

Swift with bitsets is much faster; boards are still generated off the main thread and
the next level is prefetched while you play.

## Correctness argument

Every LogicSolver technique only removes cells that can never hold a cat in *any*
solution. So if it places all N cats, that placement is the only solution. The game
judges a cat against the stored solution, which is therefore always the one answer.
